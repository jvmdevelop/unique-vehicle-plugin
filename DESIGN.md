## Система координат

Плагин использует **систему координат машины** (vehicle-space), повёрнутую с yaw'ом транспортного средства:

```
         +Z (вперёд, в сторону, куда смотрит водитель)
          |
          |
-X -------+------- +X (вправо от водителя)
          |
         -Z (назад)
```

- **X+** — правая сторона (от взгляда водителя)
- **X-** — левая сторона (от взгляда водителя)
- **Y+** — вверх (мировые координаты, не вращается вместе с машиной)
- **Z+** — вперёд
- **Z-** — назад

> Пример: левое колесо имеет `offset.x: 0.6875`, правое — `offset.x: -0.6875`.

## Создание модели в Blockbench

### Требования к проекту

При создании нового проекта в Blockbench выбирай **Java Block/Item**.

- Формат: `java_block`
- Разрешение текстуры: 32×32 (для мелких деталей) или 128×128 (для рамы кузова)
- Начало координат (origin): `[0, 0, 0]` — это центр вращения/позиционирования детали в игре

### Как должны быть расположены детали

Вся геометрия в Blockbench строится в пикселях (16 пикселей = 1 блок в Minecraft). **Начало координат модели `[0, 0, 0]` будет точкой, которую плагин помещает в мировые координаты детали.**

Поэтому:
- Центрируй деталь вокруг `[0, 0, 0]` так, чтобы это было логическим центром (или центром вращения).
- Для колеса — центр должен быть на оси колеса.
- Для двери — начало координат должно находиться на петле двери.
- Для рулевого колеса — в центре круга.

### Кузов (Frame)

Кузов — статичная деталь, не вращается. Строй свободно.

- Размер примерно 2–3 блока в длину (32–48 пикселей по Z), 1–1.5 блока по X, 1 блок по Y.
- Центр по X и Z желательно оставить в `[0, 0]`.
- Нижняя грань кузова — примерно `y: -8` (−0.5 блока, т.к. плагин добавляет offset.y для подъёма).

### Колёса (Wheel)

Колёса **вращаются по оси X** (прокрутка) и **поворачиваются по оси Y** (передние — руление). Центр вращения — ось колеса.

- Центр модели колеса должен быть в `[0, 0, 0]`.
- Ось колеса идёт вдоль X (колесо плоское в плоскости YZ).
- Радиус примерно 7 пикселей (0.44 блока) — это влияет на скорость анимации прокрутки.

```
  Вид спереди (колесо в плоскости YZ):

       +Y
       |
  -Z --+-- +Z
       |
       -Y

  Ось вращения — X (уходит в экран)
```

**Важно**: у правого и левого колеса **одна и та же модель**. Зеркальное отражение правого колеса делается автоматически плагином (масштаб по X становится отрицательным для правого).

### Дверь (Door)

Двери **вращаются по оси Y** (открытие). Начало координат — на петлях двери (передний край).

- Дверь строится для **левой стороны** (тип LEFT). Правая дверь — это та же модель, зеркально отражённая по X.
- Петля двери (точка поворота) должна быть у `x: 0, z: 0`.
- Дверь вытянута в стороны по X (ширина) и по Z (длина, в сторону передка машины).
- Угол открытия: 70°.

```
  Вид сверху (открытие двери):

  Z (вперёд)
  ^
  |   ←── дверь закрыта
  |
  +---петля
       \
        \  ←── дверь открыта (70°)
```

### Рулевое колесо (Steering Wheel)

Рулевое колесо **вращается по оси Z** (влево/вправо, ±30°). Центр модели — центр руля.

- Руль расположен в плоскости XY (смотрит вперёд по Z в сторону водителя).
- Центр круга руля — в `[0, 0, 0]`.

## Экспорт из Blockbench

1. В Blockbench: **File → Export → Export Block/Item Model** (`.json`).
2. Файл будет в формате Minecraft Item Model JSON.
3. Помести `.json` в ресурспак по пути:
   ```
   resourcepack/assets/minecraft/models/item/vehicle/<название>.json
   ```
4. Добавь текстуру `.png` в:
   ```
   resourcepack/assets/minecraft/textures/item/vehicle/<название>.png
   ```

### Пример структуры экспортированного JSON

```json
{
  "format_version": "1.9.0",
  "credit": "Made with Blockbench",
  "texture_size": [32, 32],
  "textures": {
    "0": "item/vehicle/wheel",
    "particle": "item/vehicle/wheel"
  },
  "elements": [
    {
      "from": [-1, -7, -7],
      "to": [1, 7, 7],
      "faces": {
        "north": {"uv": [0, 0, 16, 16], "texture": "#0"},
        "east":  {"uv": [0, 0, 2, 16],  "texture": "#0"},
        "south": {"uv": [0, 0, 16, 16], "texture": "#0"},
        "west":  {"uv": [0, 0, 2, 16],  "texture": "#0"},
        "up":    {"uv": [0, 0, 16, 2],  "texture": "#0"},
        "down":  {"uv": [0, 0, 16, 2],  "texture": "#0"}
      }
    }
  ]
}
```

> Путь текстуры в JSON должен быть относительным путём в пределах ресурспака: `"item/vehicle/wheel"` означает `assets/minecraft/textures/item/vehicle/wheel.png`.

## Структура ресурспака

```
resourcepack/
└── assets/minecraft/
    ├── items/
    │   └── barrier.json          ← привязка Custom Model Data → модель
    ├── models/item/vehicle/
    │   ├── frame.json
    │   ├── door.json
    │   ├── wheel.json
    │   └── steering_wheel.json
    └── textures/item/vehicle/
        ├── vehicle_frame.png     (128×128)
        ├── door.png              (32×32)
        ├── wheel.png             (32×32)
        └── steering_wheel.png   (32×32)
```

### Файл barrier.json (items/)

Каждая деталь машины — это предмет **BARRIER** с разным `custom-model-data`. В этом файле прописываются переопределения:

```json
{
  "model": {
    "type": "minecraft:model",
    "model": "minecraft:item/generated",
    "overrides": [
      {
        "predicate": { "minecraft:custom_model_data": 1 },
        "model": "minecraft:item/vehicle/frame"
      },
      {
        "predicate": { "minecraft:custom_model_data": 2 },
        "model": "minecraft:item/vehicle/steering_wheel"
      },
      {
        "predicate": { "minecraft:custom_model_data": 3 },
        "model": "minecraft:item/vehicle/door"
      },
      {
        "predicate": { "minecraft:custom_model_data": 4 },
        "model": "minecraft:item/vehicle/wheel"
      }
    ]
  }
}
```

> Числа `custom-model-data` должны совпадать с теми, что указаны в `config.yml` для каждой части.

## Конфиг машины

Файл: `src/main/resources/config.yml`

Каждая машина задаётся в секции `vehicles.<id>`. Поддерживаются несколько машин одновременно.

### Структура секции детали (part)

```yaml
material: BARRIER          # Всегда BARRIER
custom-model-data: 1       # Номер CMD (совпадает с barrier.json)
offset:
  x: 0.0                   # Смещение по X от центра машины
  y: 0.0                   # Смещение по Y (высота)
  z: 0.0                   # Смещение по Z от центра машины
pivot:                     # ТОЛЬКО для деталей, которые вращаются
  x: 0.0
  y: 0.0
  z: 0.0
```

### Поддерживаемые части

| Ключ конфига | Вращение | Ось | Pivot нужен |
|---|---|---|---|
| `frame` | Нет | — | Нет |
| `steering-wheel` | Да (±30°) | Z | Да |
| `doors[].type: LEFT` | Да (+70°) | Y | Да |
| `doors[].type: RIGHT` | Да (−70°) | Y | Да |
| `wheels[].front: true` | Да (прокрутка + руление) | X + Y | Да |
| `wheels[].front: false` | Да (прокрутка) | X | Да |
| `seat` | Нет | — | Нет |

## Система пивота

**Pivot** — это точка вращения детали в локальном пространстве модели (в блоках, не пикселях).

Плагин вычисляет трансляцию так, чтобы деталь вращалась вокруг точки pivot, а не вокруг своего origin:

```
translation = pivot - rotation(pivot)
```

Это значит: если модель колеса имеет центр в `[0, 0, 0]`, но реальный центр оси немного смещён (например, из-за толщины шины), нужно указать этот сдвиг в pivot.

### Как вычислить pivot

1. Открой модель в Blockbench.
2. Найди центральный куб или грань, вокруг которой должно происходить вращение.
3. Посмотри координаты этой точки в **Blockbench-единицах** (пиксели).
4. Переведи в блоки: `блоки = пиксели / 16`.
5. Впиши в конфиг.

**Примеры из реального конфига:**

| Деталь | Pivot | Причина |
|---|---|---|
| Колесо | `x: 0.0625, y: 0, z: 0` | Центр оси немного смещён от origin (1 пиксель) |
| Руль | `x: 0.0313, y: 0.0625, z: 0` | Центр круга руля чуть смещён |
| Дверь | `x: 0, y: 0, z: 0` | Петля совпадает с origin |

### Настройка pivot в игре

Команда `/vehicle editor` открывает GUI, где можно в реальном времени подбирать offset и pivot для каждой детали с шагом 0.0625 (1/16 блока). Изменения сохраняются в SQLite. Это удобно для точной подстройки без перезапуска сервера.

## Физика

Секция `physics:` в конфиге машины:

```yaml
physics:
  max-speed: 1.2              # Максимальная скорость вперёд (блоков/тик)
  acceleration: 0.05          # Ускорение (блоков/тик²)
  friction: 0.02              # Трение (потеря скорости за тик без ввода)
  turn-rate: 3.5              # Скорость поворота (градусов/тик при макс. скорости)
  brake-force: 0.08           # Торможение (блоков/тик²)
  reverse-max-speed: 0.4      # Максимальная скорость назад
  reverse-acceleration: 0.03  # Ускорение задним ходом
  drift-brake-force: 0.04     # Торможение во время дрифта
  drift-turn-multiplier: 1.8  # Множитель поворота в дрифте
  vehicle-width: 0.8          # Ширина (для проверки коллизий)
  vehicle-length: 1.2         # Длина (для проверки коллизий)
```

**Советы по настройке:**
- `max-speed: 1.2` — это ~24 блока/секунду (20 тиков × 1.2). Реалистично для машины.
- `turn-rate` зависит от скорости: на малой скорости поворот медленнее.
- Если машина слишком скользкая — уменьши `friction`.
- Если слишком резко реагирует на руль — уменьши `turn-rate`.

## Полный пример конфига

```yaml
vehicles:
  my_car:
    # Кузов машины
    frame:
      material: BARRIER
      custom-model-data: 1
      offset:
        x: 0.0       # Центр по X
        y: 0.25      # Приподнят на 0.25 блока
        z: 0.0       # Центр по Z

    # Рулевое колесо
    steering-wheel:
      material: BARRIER
      custom-model-data: 2
      offset:
        x: 0.125     # Немного правее центра (водитель слева)
        y: 0.75      # На уровне груди водителя
        z: 1.75      # Ближе к переднему краю
      pivot:
        x: 0.0313    # Центр руля по X (0.5 пикселя)
        y: 0.0625    # Центр руля по Y (1 пиксель)
        z: 0.0

    # Двери (всегда 2: LEFT и RIGHT)
    doors:
      - type: LEFT
        material: BARRIER
        custom-model-data: 3
        offset:
          x: 0.6875    # Левая сторона (+X)
          y: 0.875     # На уровне дверей
          z: 1.125     # Середина кузова по Z
        pivot:
          x: 0.0
          y: 0.0
          z: 0.0

      - type: RIGHT
        material: BARRIER
        custom-model-data: 3
        offset:
          x: -0.6875   # Правая сторона (-X)
          y: 0.875
          z: 1.125
        pivot:
          x: 0.0
          y: 0.0
          z: 0.0

    # Колёса (4 штуки: 2 передних, 2 задних)
    wheels:
      - type: LEFT           # Переднее левое
        front: true
        material: BARRIER
        custom-model-data: 4
        offset:
          x: 0.6875
          y: 0.4375          # Центр колеса по высоте
          z: 1.375           # Ближе к переду
        pivot:
          x: 0.0625          # 1 пиксель — ось колеса
          y: 0.0
          z: 0.0

      - type: RIGHT          # Переднее правое
        front: true
        material: BARRIER
        custom-model-data: 4
        offset:
          x: -0.6875
          y: 0.4375
          z: 1.375
        pivot:
          x: 0.0625
          y: 0.0
          z: 0.0

      - type: LEFT           # Заднее левое
        front: false
        material: BARRIER
        custom-model-data: 4
        offset:
          x: 0.6875
          y: 0.4375
          z: 0.0             # Ближе к центру/зад
        pivot:
          x: 0.0625
          y: 0.0
          z: 0.0

      - type: RIGHT          # Заднее правое
        front: false
        material: BARRIER
        custom-model-data: 4
        offset:
          x: -0.6875
          y: 0.4375
          z: 0.0
        pivot:
          x: 0.0625
          y: 0.0
          z: 0.0

    # Место водителя
    seat:
      offset:
        x: 0.2375    # Немного правее (водитель — ближе к центру)
        y: 0.5       # На высоте сиденья
        z: 1.5       # В зоне сиденья

    # Физика
    physics:
      max-speed: 1.2
      acceleration: 0.05
      friction: 0.02
      turn-rate: 3.5
      brake-force: 0.08
      reverse-max-speed: 0.4
      reverse-acceleration: 0.03
      drift-brake-force: 0.04
      drift-turn-multiplier: 1.8
      vehicle-width: 0.8
      vehicle-length: 1.2
```

## Чеклист создания новой машины

- [ ] Создан проект в Blockbench (формат: Java Block/Item)
- [ ] Кузов: центрирован по XZ, нижний край ~`y: -8`
- [ ] Колёса: центр в `[0,0,0]`, ось вращения — X
- [ ] Двери: петля в `[0,0,0]`, строится для левой стороны
- [ ] Руль: центр круга в `[0,0,0]`, модель в плоскости XY
- [ ] Все модели экспортированы в `resourcepack/.../models/item/vehicle/`
- [ ] Текстуры размещены в `resourcepack/.../textures/item/vehicle/`
- [ ] `barrier.json` обновлён с нужными `custom-model-data`
- [ ] Конфиг в `config.yml` заполнен для новой машины
- [ ] Offset и pivot подстроены через `/vehicle editor`
